# Sumanth Bharadwaj — Portfolio

A single-page portfolio website showcasing Data Science, ML Engineering, and NLP experience.

## Quick Start

Open `index.html` in any browser, or run a local server:

```bash
# Python
python -m http.server 8000

# Node (npx)
npx serve .
```

Then visit `http://localhost:8000`

## Deployment

- **GitHub Pages**: Push to a repo and enable Pages in Settings
- **Netlify**: Drag & drop the `portfolio` folder
- **Vercel**: `vercel ./portfolio`

## Customization

- **LinkedIn**: Update the link in the nav, hero meta, and contact section
- **Email**: Already set to `sh8111@nyu.edu`
- **Content**: Edit `index.html` to add projects, update experience, etc.

## Tech

- Vanilla HTML, CSS, JS (no build step)
- Syne + JetBrains Mono fonts (Google Fonts)
- Responsive, dark theme, scroll animations
